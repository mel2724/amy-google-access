This page describes the Google connection for Melissa OS Amy Read Only, a personal assistant operated by Melissa Sands.

Information accessed

When the owner authorizes Google access, Amy can read the account email address, Drive file listings and metadata, file content available through Drive, Docs document content, and Sheets spreadsheet metadata and cell values. It requests only these Google scopes: userinfo.email, drive.readonly, documents.readonly, and spreadsheets.readonly.

Why it is used

Information is used to find, retrieve, summarize, and reason about the owner’s information in response to the owner’s tasks. The connection does not permit changes to Google files or their sharing settings.

Processing and transfers

Google provides the source data. Composio handles the authorized Google connection, stores and refreshes its OAuth credentials, and processes requested tool calls. Requested results are returned to the owner’s Hermes assistant. When a task uses an AI model, relevant results may be processed by the configured model provider to produce the response. The connection does not provide public access to the owner’s files.

Storage and retention

OAuth credentials are held by Composio. The local assistant’s Composio credential is kept in account-restricted local storage. Retrieved information may remain in assistant conversations, local records, and owner-controlled backups. Revoking Google access prevents future authorized retrieval; it does not automatically erase existing conversations or backups. The owner controls review and deletion of retained local information.

Limited use

Google user data is used for the personal assistant functions described here. This integration does not sell Google user data, use it for advertising, or use it to train a general-purpose AI model. Its use and transfer of Google API information will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and requests

Revoke the app’s access through Google Account connections. For questions or requests about retained information, contact mel2724@gmail.com. Google, Composio, and configured model providers also apply their own service policies.

This website

These static information pages do not request Google credentials, contain private account data, or use analytics or advertising scripts. The hosting provider may process ordinary web request logs under its own policies.
